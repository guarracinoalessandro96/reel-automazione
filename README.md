# Reel automazione

Pubblica in automatico i reel di Alessandro su Instagram, Facebook, YouTube Shorts e TikTok
alle 9, 12, 15, 18 e 21 (ora italiana). Vedi GUIDA COLLEGAMENTO nella cartella Drive.

- `pubblica.py` pubblicazione, `overlay.py` testo sul video + musica, `orario.py` orari
- `captions.json` coda delle caption, `musica/` loop originali, `docs/` sito (gara follower, privacy)
